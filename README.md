# 🛠️ MLOps Zoomcamp 2025 – Assignment Solutions

This repository contains the **solutions to the exercises and homework assignments** for each module of the [MLOps Zoomcamp](https://github.com/DataTalksClub/mlops-zoomcamp), a free 9-week course on productionizing machine learning services.

## 📂 Repository Structure

Each folder corresponds to a module and includes scripts, notebooks, and configuration files needed to reproduce the exercises and homework:


## 🧑‍💻 How to Use This Repository

1. **Clone the repository**

   ```bash
   git clone https://github.com/your-username/your-mlops-zoomcamp-repo.git
   cd your-mlops-zoomcamp-repo
   ```

2. **Create and activate a virtual environment**

   **On Linux/macOS:**
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

   **On Windows:**
   ```powershell
   python -m venv .venv
   .venv\\Scripts\\activate
   ```

3. **Install dependencies** as needed in each module (check each folder's \`requirements.txt\` if applicable).
